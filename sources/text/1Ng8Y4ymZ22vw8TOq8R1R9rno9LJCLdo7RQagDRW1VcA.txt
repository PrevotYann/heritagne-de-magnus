
LE PACK PHYSIQUE LÉGENDAIRE





	Si vous avez participé à la campagne Ulule et que vous avez pris un Pack Légendaire, j’explique ici tout le fonctionnement élément par élément.





Les Cartes :

Vous trouverez dans le Pack différentes cartes des villages et villes de la région avec le nom des villes écris dessus. Vous pouvez donner IRL aux joueurs au moment ou ils en détiennent une RP.





Les Lettres et Messages Corbeaux :

Dans le jeu il existe un système de courrier (voir Le Courrier). Des lettres sont liées à certaines Quêtes, certains personnages, et parfois sont destinés aux joueurs. 

Pour les lettres, celle de Magnus pour les joueurs est dans une enveloppe à part, le reste des lettres sont marquées d’un code pour les différencier.

Pour les messages de corbeaux, ils sont également marqués d’un code pour les différencier. Dans le doc des messages corbeaux pour le MJ, il est inscrit le code couleur de l'élastique et le nombre de points et de bâtonnets indiqués sur le petit parchemin.
