La chambre d’Anti-Lois : (Piltover)



C’est une pièce écrite par des lois qui peuvent changer selon la position d’étiquettes.



Par exemple, si l'étiquette Pierre est dans la case solide, alors les murs en pierres sont solides mais si on la déplace dans la case liquide, alors les murs en pierre deviennent liquides. Si par défaut ils ne sont pas dans une case alors ils sont dans leur état normal. Ils peuvent avoir plusieurs cases, par exemple Pierre dans Solide et Lourd ou Liquide et Brûlant.



Les étiquettes sont : Pierre / Bois / Métaux / Air / Feu / Eau / Corps / Gravité /  Les cases sont : Liquide / Solide / Mou / Gazeux / Léger / Lourd / Brûlant / Glacé / Immatériel / Stase
